## 📓 Lucilia's Notebook (`/project/notebook`)

Caderno digital interativo de anotações e laboratórios práticos sobre desenvolvimento de software full-stack, linguagens de programação, bancos de dados e metodologias.

### 🌟 Estrutura do Projeto

- **`notebook.html` / `index.html`**: Página principal do projeto com catálogo navegável por temas, busca rápida e navegação fluida.
- **`chatbot.js`**: Assistente virtual interativa construída em JavaScript puro para responder dúvidas sobre os tópicos de estudo.
